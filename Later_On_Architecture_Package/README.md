**小五 × 小梦，一段由你选择怎样继续的漫画故事。**

本目录是《后来呢》的剧情、技术架构和场景美术设计包，作为独立于 SECOND NATURE 的新项目起点。

目标项目目录：`D:\新建文件夹\java\javacode\后来呢`。

## 先读什么

1. [完整分支剧本](docs/STORY_SCRIPT.md)：33 个节点，逐句台词、选择后的回应、交错路线和 4 个结局。
2. [游戏架构](docs/ARCHITECTURE.md)：对话播放、分支判定、场景渲染、鼠标与手势、存档和开发顺序。
3. [场景与美术方案](docs/SCENE_RENDERING.md)：人物设定、33 节点逐幕画面、27 类基础构图、29 张基础背景交付及素材变体。
4. [场景清单](docs/SCENE_MANIFEST.json)：供后续开发读取的节点、跳转、构图、背景、人物阶段和素材需求索引；不代替正文台词。
5. [验收与实施清单](docs/ACCEPTANCE.md)：怎样判断剧情、画面和交互做到了本次要求。

## 已确定的体验

- 玩家为男主角小五；女主角为小梦。
- 鼠标和手势都能完整游玩，打开页面即可用鼠标；手势由玩家主动开启。
- 漫画人物旁的气泡一次说一句话，少量旁白；只有换场景才替换背景，日常对话保留画面。
- 选择影响回应、关系经历、后续场景及结局。4 种结局中只有 E01 为两人持续相恋的圆满结局。
- 沿用 SECOND NATURE 现有的粗线条、低饱和手绘彩色卡通风格，场景内容更贴近校园恋爱与成年生活。恋爱人物需要完整表情，不能照搬参考图中弱化五官的处理。
- 不显示好感分数、答题对错或选项倒计时。
