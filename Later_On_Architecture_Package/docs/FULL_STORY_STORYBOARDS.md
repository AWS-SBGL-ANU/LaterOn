# 全篇静态插画与沉浸阅读

## 对白与画面

- `src/data/storyboards.json` 按节点、对白／回应、选项、对白 ID 精确绑定画面。
- 每幅最多承接三条对白。动作行及原分镜动作变化立即开启下一镜，不等待后面几句。
- 远景、双人中景、肩后视角、人物反应、手部与道具特写分别绘制，避免用同图缩放代替新画面。
- 耳机接过后的第一句就使用戴好耳机的画面；递出耳机的另一分支仍保持未佩戴。
- 借笔的指尖接触、笔跌落、地面、同时伸手、近距离抬眼、拾起、继续写字分别成镜。接触格已专门修正两根手指实际贴合。
- 所有插画保持静态，不加载人物关节或动作时间线。当前镜头准备好之后，才提交推进剧情或选项。
- 存档结构和正文对白 ID 保持，重新加载仍会选中同一幅细分插画。

详细逐镜内容见 [ILLUSTRATED_STORYBOARD.json](ILLUSTRATED_STORYBOARD.json)。重排方案脚本为 `scripts/plan-storyboards.mjs`；修改剧本后，应核对逐镜内容并补齐相应插画，不能只生成绑定而不更新图像。

## 全屏与衔接

- 点击开始或继续游戏时，在该次用户操作中请求浏览器全屏；浏览器拒绝时仍使用覆盖整个窗口的阅读布局，右上方可再次进入全屏。
- 阅读界面覆盖窗口，隐藏原页面页眉、章节栏和底部工具栏。插画按单格原始像素限制显示，完整居中于暖白画布；对白和选项保留在下方，不再强行拉伸插画。
- 时间与地点变化使用黑底旁白，交代从上一段到这一段的过程。旁白不自动跳过，由点击、空格或 Enter 继续。
- 同一场小桥谈话、同一次毕业谈话的即时延续保留当前交流，不为每幅插画打断一次。
- 不引入人物动画、运镜或淡入淡出。
