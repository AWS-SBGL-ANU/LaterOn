# 《后来呢》人物动作与选项分镜

更新：2026-10-25。当前采用透明人物部件的二维关节动画，人物、正文分镜与带标题的新封面统一采用简练铅笔线、轻淡彩和暖白留白，不依赖视频、外部动画库或联网服务。81 格分镜的剧情与时序保留，图像本轮全部重绘。

## 素材与绑定

- public/art/puppets/soft-parts.png：参照新封面重新生成的透明素材，1254×1254；共16个独立部件，包含睁闭眼头部、身体、四条手臂、四条裤腿、蓝笔与冰淇淋道具。女孩与封面一致穿牛仔蓝长裤。
- PuppetPart.vue：从 src/data/puppetParts.json 读取实际边界，避免沿用旧尺寸或截断头发、手指。边界由 scripts/measure-puppet-parts.mjs 对透明图进行像素分析生成，源图不作滤镜或调色处理。
- PuppetStage.vue：组合关节、简洁场景及道具；头像、手臂和双腿分别控制。
- StoryProp.vue：笔记、申请表、日历、手机、水、保温杯、勺子、筷子、纸巾、纸星星、橡皮、钥匙、球、麦克风、早餐和购物袋等场景道具。
- choreography.mjs：现有动作镜头和全部 39 个节点、105 个选项的回应绑定。
- puppetTimeline.mjs：关节位移、角度与道具位置的关键帧及平滑插值。
- sceneDirections.mjs：逐段匹配 39 个节点中的 149 处具体动作说明，包括动作型旁白，不靠孤立动词误触发回忆中的动作。
- detailedMovements.mjs：为具体动作配置准备、移动、等待、接触和收回等细分阶段，允许不等时长和原位停顿。逐条对应见 [ACTION_COVERAGE.md](ACTION_COVERAGE.md)。

## 连续动作

| 段落 | 动作 |
| --- | --- |
| 借笔 | 伸手递笔 → 指尖相触 → 笔落下 → 弯腰 → 抬头 → 捡起 → 写字 |
| 长椅 | 扶杯递近 → 取食 → 尝一口 → 害羞转头；另拿勺子时保留杯子和原来的一把勺子 |
| 热水 | 倾斜保温杯，对准独立杯子；再把杯子捧近 |
| 公交 | 示意肩膀 → 靠近并轻靠 → 叫醒后坐正；其他选项使用各自回应 |
| 牵手 | 伸手等待 → 双方手臂靠近 → 保持牵手 |
| 机场 | 拉链 → 早餐 → 等待回应 → 张开双臂 → 迈步靠近 → 合拢双臂 → 停留 → 松开并退回 |
| 成年日常 | 两人分担购物袋、做饭、递勺、查看计划与钥匙 |
| 告别 | 挥手、垂下手臂、收好手机、迈步离开；异地对话保持两边的画面分隔 |

走动时双腿交替摆动，头部与手臂有独立关节，不能把整幅插画平移称作人物走路。前后动作接续上一动作的关节姿势；进入新节点则重新布置人物位置。成年人物增加工牌线索。

## 全剧情动作细化

2026-10-25 接续修订不只覆盖捡笔，已把具体动作扩展到全剧 149 处说明：

- 递耳机、递水、豆奶、纸巾、筷子和勺子：先拿稳 → 递近 → 停住等待 → 对方伸手接稳 → 递出的一方再收手。
- 推本子、推面碗、推杯垫：沿桌面移动，手指压住一角，等对方接住后才松开；翻页和写字使用不同的手腕运动。
- 分享冰淇淋：杯子和勺子分层，勺上出现一小口冰淇淋，送到唇边后消失，再降低手臂；纸杯始终留在原处。
- 伞下相处：举稳、偏向对方、等人站稳、被轻推回来、最后停在两人中间。背包挪开和人物靠近分别控制。
- 倒水：拧盖、独立放下杯盖、对准另一个杯子、倾斜并出现水流、停顿、扶正杯身，结束时关闭水流。
- 公交：困倦轻晃后自己坐正、指肩后不好意思地收手、等待回应、慢慢靠近、接触衣领、把手机放回膝上、安静停留、轻声叫醒并等她坐稳。
- 纸星星：旧本子放下、星星滑落、手掌接住、短暂停留、收进书包；勾小指后用另一只手拉好书包。
- 机场、桥边和大学重逢：保留各自的等待和回应；桥边的小梦只抓住袖口，不套用机场拥抱中已经回抱的姿势。
- 其他日常与告别：整理稿纸、挪椅子、扶车、静音工作群、反复开关回放、犹豫后挂断、垫好旧笔记、收手机、上车挥手、收手后走开等均有独立阶段。

手腕从袖子中独立出来，细小转动不会带着整个上臂转动。每阶段在画面底部显示简短动作描写；阶段播放不会自动翻到下一句。B10 的工作邀请谈话按同一房间呈现，异地通话仍保持画面分隔。

## 阅读控制

- 动作自身可以播放到结束，但绝不自动进入下一句或替玩家选择。
- 点击先补全当前文字；文字已完整而动作未完成时，点击补完动作，再点击才继续。
- 普通对白沿用动作后的姿势，不重复播放。恢复已读过动作后的对白、选择页及结局时，直接显示相应完成姿势。
- 菜单、加载、错误、存档冲突与隐藏标签页暂停 requestAnimationFrame；恢复后从已播放的位置继续。
- 减少动态设置和系统减少动态偏好均直接显示完成姿势。
- 拥抱只在剧本实际拥抱动作开始后播放。选择拥抱选项时先保留倾听；机场、桥边和大学重逢各自检查对应动作句。
- 动作状态由现有剧本进度推导，不修改存档结构或剧情版本。
- 素材预加载同时包含对应图集和透明人物部件；失败不提交选择或推进。
