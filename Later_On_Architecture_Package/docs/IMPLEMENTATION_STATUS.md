# 《后来呢》实施进度

更新：2026-10-24。当前阶段：全剧情可玩版，可本地运行。

## 当前可用

- Vue 3、TypeScript、Pinia、Vite 独立项目；`npm run dev` 启动，`npm run build` 生成静态部署文件。
- 33 个节点、619 条对白与动作、4 个结局；全部选项附有回应，没有回答倒计时或好感分数。
- 逐句阅读、条件回忆、朋友路线、坦诚告别、关系耗尽、修复及日常生活路线。
- 8 张 Q 版淡彩手绘图集，索引 29 个场景/年龄环境，另有 3 幅结尾画面；舞台单次显示一幅画面。
- 同场分支保留背景；跨场淡出、字幕、淡入。下一幅画面加载成功后才推进故事。
- 结尾画面在最后一句心声及完成后保持，刷新恢复时加载同一幅画面。
- 插画失败可重试或使用简化画面。恢复当前画面时不会跳过回应，加载下一幅画面失败时不提交剧情推进。
- 自动存档、JSON 导入导出、从检查点重选、已读结局、多个标签页写入冲突提示。
- 导入时校验对白来源、路线、状态、历史与检查点；无效导入保留当前进度。导入已读完的结局可恢复回忆解锁。
- 鼠标、键盘；可主动开启 MediaPipe 手势，识别资源在本地提供。
- 固定整屏漫画画布，不产生页面上下滚动；对白位于画面内人物头顶附近，男生左上、女生右上，选项在画面下方展开。
- 逐字显示对白；点击气泡或画面先补全当前句，再点击推进，键盘及手势同样经过此流程。切换说话者时重置显示，打开菜单时暂停；减少动态效果则直接显示整句。
- 24/28/32px 对白字号，默认 28px；优先使用圆润幼圆/圆体系统字体，减少动态效果、环境音、对白日志、选择历程。

## 验证

`npm run check` 依次执行 16 项自动测试、资源完整性检查和 TypeScript/生产构建。

自动测试包括五条指定路线、33 节点可达及全部分支终止、条件回忆、回应恢复、多标签页冲突、逐句存档往返、无效导入拒绝、同场保留、跨场预加载计划、年龄环境及结尾画面连续性。

本次浏览器检查：恢复 S01 选项回应、逐句读完回应、淡出至 S02、打开关闭设置、28px 字号显示。摄像头没有在本次浏览器验证中启用。

新版界面已检查 1366×768、1024×600、620×540、390×844 和 844×390：页面尺寸与视口一致，气泡及全部选项位于漫画画布内；另检查左右说话者切换后的逐字显示、32px 设置及选项展开。逐字显示的四项测试覆盖逐字符推进、补全、切换/取消计时器、暂停恢复及即时显示。

## 尚未完成的原始美术规划

- 原架构的 48 张透明人物素材、逐句更换姿态和表情尚未制作。现版人物绘在完整插画中，笔记、雨与文字使用独立图层。
- 图集每幅场景约 836×470，尚未达到原规划的单幅 1920×1080 交付尺寸。
- 未逐一制作全部选项的动作变化，例如拥抱、移动座位、耳机交接与笔记闭合；不能称为全部分支动作均已渲染。
- 真实摄像头、权限拒绝、手势全流程与设备差异仍待实际设备验收；不可将资源完整性检查视为识别效果验收。
- 没有发布到公网。

`SCENE_MANIFEST.json` 仍作为原始设计索引，其中独立背景文件的 `planned` 状态与路径描述的是原始分层素材计划；当前实际插画映射以 `src/domain/presentation.mjs` 为准。画风继续以 `ART_DIRECTION_LOCK.md` 为准。
