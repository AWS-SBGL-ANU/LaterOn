# 《后来呢》最终画风确认

确认日期：2026-10-24。用户在看到教室双人 Q 版淡彩手绘样图后明确确认“对的对的”。本文件覆盖旧架构和 SCENE_RENDERING.md 中冲突的画风描述。

## 唯一执行标准

- Q 版人物，约 2—2.5 头身，大头、小身体、小手脚。年龄增长通过服装、道具和发型体现，始终保留 Q 版比例。
- 蓬松、有自然碎发的发型；小五深棕短发，小梦深棕低马尾。不能换场就换脸。
- 细而自然的棕色手绘线条，保留轻微铅笔随手感；淡彩、温暖、柔和，有少量腮红。
- 简洁的眼睛、小嘴和眉毛；情绪由表情、朝向、人物距离与动作表达。
- 背景与人物统一使用淡彩手绘语言。画出每个地点特有的物件、天气与生活内容，避免压过人物。
- 游戏舞台仍为 16:9。已确认的方形样图只确定画风，不能把方图拉伸成横图。
- 台词、标题和按钮由界面显示，插画里不生成台词或文字。

## 已否决的方向

- 普通人体比例的校园动漫人物。
- Second Nature 旧图的粗黑轮廓与硬边平涂；旧参考仅保留完整环境与交互布局的借鉴。
- 写实、3D、塑料质感、厚涂、电影式光影和精修商业日漫立绘。
- 只有空背景或简单几何占位人物。

## 制作与检查

先用同一份人物设定核对高中、大学、成年阶段。每幅画与已确认样图核对头身比、线条、发量、脸型和色彩，不能仅凭“手绘”“卡通”等宽泛标签判断一致。游戏剧情、33 节点、4 结局、鼠标与可选手势、逐句对白及淡入淡出规则继续沿用现有架构。

已有的旧看台背景不是最终画风素材，不得当作正式游戏插画使用。游戏和其他正式美术尚未完成，确认样图不代表全部素材已交付。
