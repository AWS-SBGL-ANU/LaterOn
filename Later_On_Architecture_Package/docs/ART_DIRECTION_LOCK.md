# 《后来呢》最终画风确认

确认日期：2026-10-25。以本次用户确认的“可以更加粗糙一点”“只把两人周围的小世界渲染出来”“每个动作分设一个场景”为准。本文件覆盖旧稿中的细线精修、完整环境、原人物发型及服装要求。

## 当前执行标准

- 原创 Q 版大头小身体，蓬松头发、简单眉眼、小手脚。粗糙铅笔草线、重叠线、蜡笔缺口与少量淡彩，保留不整齐的手绘痕迹。
- 小五：蓬松黑短发、灰蓝/青绿外套、米色长裤；小梦：蓬松棕色短发、黄色星星发夹、浅黄外套与蓝色衣物。人物外形以 public/art/sketch/pen.png 为母版，新场景延续同一套外形。成年用工牌、围裙、行李等生活道具区分。
- 双人画面固定小梦在左、小五在右；气泡按实际角色位置显示，不因为说话顺序翻转人物。
- 只描绘人物和身边必要的桌椅、笔、杯、伞、行李等物件。地点可以辨认，画面其余部分向暖白纸面收掉，不追求复杂背景。
- 参考图只提供粗糙线条、人物占比与局部世界的方向；不得照搬参考人物、行李玩偶组合或原构图。
- 画面为 16:9；九格图集按 3×3 绑定，每格作为独立镜头播放。无需裁切或拉伸方图。
- 连续人物动作使用 public/art/puppets/parts.png 的粗铅笔透明部件，头部、身体、手臂与双腿分别绑定，避免把整张插画漂移当作伸手或走路。人物左女右男、发型、发夹和服装配色继续保持。
- 文字、选项和标题由界面显示。手绘图里不生成对白、标题或水印。

## 分镜与情节

- 一次只推进一句话，玩家主动点击；没有自动翻页或选项倒计时。
- 场景不是一张图配完所有动作。递笔、碰到指尖、笔滚落、落地、同时弯腰、靠近、捡起、坐好，逐格对应。
- 交谈、请求、等待、靠近、实际拥抱、停留、松开分别呈现。亲密动作只出现在对应选项得到明确回应之后。
- 同一地点相邻动作轻柔溶解；跨地点、明确时间变化才淡出黑屏、显示时间地点、淡入。
- 物品有连续性。选完回应，不能把已经捡起的笔变回掉在地上，也不能让已经拿走的纸杯复位。
- 现有剧情仍为39个节点、4种结局；细节分镜在节点内部展开。实现与图集清单见 STORYBOARD.md。

## 不采用的方向

精修商业日漫、光滑厚涂、3D塑料感、电影光效、完整风景铺满画面、参考图人物或构图的直接复制，以及用同一张拥抱图替代整个靠近过程。
