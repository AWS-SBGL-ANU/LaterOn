# 《后来呢》统一美术标准

最终修订：2026-10-25。用户明确确认最新简练淡彩封面的风格适用于整款游戏，并指出旧正文插画和动画人物仍然过密、过于具体。本文件覆盖之前的粗重草线、密集蜡笔填色、旧人物部件和“仅封面更简练”的描述。

## 当前执行标准

- 原创 Q 版大头小身体，点状眼睛、简单嘴角、小手脚。用少量松散但柔和的铅笔线概括人物，轻淡色块、整体对比柔和，保留大片暖白纸面。减少密集发丝、衣褶、拉链、鞋带、木纹和粗重颗粒。
- 小五：蓬松黑短发、灰青绿外套、米色长裤；小梦：短而蓬松的棕发、黄色星星发夹、浅黄外套、宽松牛仔蓝长裤。统一以 public/art/cover-title-soft.png 为风格参考，不能只让封面变简练、正文和动画继续用旧人物。成年仅增加少量生活线索。
- 双人画面固定小梦在左、小五在右；气泡按实际角色位置显示，不因为说话顺序翻转人物。
- 只描绘人物和身边必要的桌椅、笔、杯、伞、行李等物件。地点可以辨认，画面其余部分向暖白纸面收掉，不追求复杂背景。
- 参考图只提供粗糙线条、人物占比与局部世界的方向；不得照搬参考人物、行李玩偶组合或原构图。
- 画面为 16:9；九格图集按 3×3 绑定，每格作为独立镜头播放。无需裁切或拉伸方图。
- 连续人物动作使用 public/art/puppets/soft-parts.png 的同风格透明部件，头部、身体、手臂、手腕、双腿分别绑定；实际边界见 src/data/puppetParts.json。不能静态插画换新、动作出现时又回到旧人物。
- 对白、旁白与选项由界面显示；封面是标题文字嵌入图片的明确例外。游戏首页保留可访问的文字标题，避免叠画第二个可见标题。
- 封面采用 public/art/cover-title-soft.png 的单幅构图，标题“后来呢”和副标题实际画在图片中，README 单独展示时也必须看得见游戏名称。人物与小长椅只占局部；其余为暖白留白。全部正文采用相同简练线条与轻淡彩。
- 当前资源统一经 src/data/artStyle.mjs 引用：正文 public/art/soft，动画 public/art/puppets/soft-parts.png。旧 public/art/sketch、public/art/puppets/parts.png、cover.png 和无标题的 cover-sketch.png 仅为历史文件，不被运行时代码引用，不得将旧图只改名冒充重绘。

## 分镜与情节

- 一次只推进一句话，玩家主动点击；没有自动翻页或选项倒计时。
- 场景不是一张图配完所有动作。递笔、碰到指尖、笔滚落、落地、同时弯腰、靠近、捡起、坐好，逐格对应。
- 交谈、请求、等待、靠近、实际拥抱、停留、松开分别呈现。亲密动作只出现在对应选项得到明确回应之后。
- 同一地点相邻动作轻柔溶解；跨地点、明确时间变化才淡出黑屏、显示时间地点、淡入。
- 物品有连续性。选完回应，不能把已经捡起的笔变回掉在地上，也不能让已经拿走的纸杯复位。
- 现有剧情仍为39个节点、4种结局；细节分镜在节点内部展开。实现与图集清单见 STORYBOARD.md。

## 不采用的方向

精修商业日漫、光滑厚涂、3D塑料感、电影光效、完整风景铺满画面、粗重杂乱线堆、密集发丝与蜡笔颗粒、参考图构图的直接复制，以及用同一张拥抱图替代整个靠近过程。
