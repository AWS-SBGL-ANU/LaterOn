# 后来呢

小五 × 小梦｜漫画互动恋爱游戏｜慢慢靠近 · 完整分支剧本 v2.0

游戏正式名称为《后来呢》；“一起长大的约定”保留为 E02 遗憾结局的名称。本文为剧情权威稿，画面细化以同目录 SCENE_RENDERING.md 为准。

## 阅读与呈现约定

- 玩家始终扮演小五。小梦有自己的生活、选择和边界；旁白可以进入两人的内心，呈现嘴上没说、心里在意的细节；心声不是对方已经听见的事实。脸红、靠近也不替代明确意愿。
- 【画面】是给画师和开发者的说明，不显示为正文。采用 Q 版大头小身体、蓬松头发、轻柔细线淡彩；人物与手部动作优先，背景只作少量生活线索；人物有清楚的眼神、眉毛与嘴部表情。人物与地点需要有明确区别，详见 SCENE_RENDERING.md。
- 下列每一条“人物：台词”分别占一次推进。当前说话者旁出现一个气泡，下一次推进只更新气泡、必要的表情或手部姿态，不切换整幅背景，不重载页面。
- 【旁白】用窄小字幕框，一次至多一句；【手机】用屏幕内消息气泡。前文可在对白记录中回看，不堆积在主画面上。
- 选项在本段对白结束后出现。点击或手势选中后，先播放该选项的具体回应，再进入标注的场景。选项没有倒计时。
- 鼠标点击与手势执行同一套“推进／选择”；切换操作方式不重置剧情。剧情设计不依赖操作熟练度。
- 同一场内先更新对白；进入另一个场景时才淡出、显示短时间地点字幕、淡入新画面。个别同地点的连续分支可以保留背景，仅切换表情与对话。
- 每幕只播放符合本次路线的对白。条件说明、节点编号、关系记录和结局判定不显示给玩家。
- 全稿共 39 个叙事节点，新增六段表白前的生活片段；同一节点还会按动作更换独立分镜。单次通常经历约 24—31 个节点；朋友线较短，结局回顾可提示未见场景，但不把遗憾称为失败。

## 故事的四个方向

| 结局 | 关系结果 | 主要形成过程 |
| --- | --- | --- |
| E01 后来的每一天 | 唯一圆满结局；成年后在同一座城市继续相爱 | 有真实相处与心动，也有沟通、实际履约和双方可承担的生活安排 |
| E02 一起长大的约定 | 相爱过，关系在反复回避中耗尽；重逢时小梦已婚 | 多次把问题推迟、把沉默当作替对方着想，最后错过修复 |
| E03 那句没说完的话 | 一直停在朋友的位置，没有正式交往 | 两次明确机会都选择不表达，随后各自进入新的生活 |
| E04 各自的远方 | 认真相爱或尝试过，坦诚承认未来无法兼顾，告别 | 愿望不再一致，双方选择尊重；不是对玩家的惩罚 |

圆满不要求所有选项“选对”。早期拘谨、玩笑、没空看球都不会直接判定坏结局。重要的是承诺是否做过、做不到时是否说明，以及对方是否仍愿意继续。结局之间没有好感分数排名。

## S01｜借你一只耳朵

【时间】高一军训最后一晚。

【旁白】看台很宽，他却只看见她身旁那半个空位。

【小五心声】我其实可以坐别处。

【旁白】他把水杯拿起来，又放下，给自己找了个开口的理由。

【画面】操场看台。远处学生在调试音响，旗绳贴着旗杆。小梦坐右侧，帽子放在膝上；小五站左侧台阶，脚边是落下的水杯。夜色用蓝灰色和少量排线表现。耳机线是两人之间主要的视觉联系。

【旁白】汇演还没开始，音响已经响了三遍。

1. 小五：这个杯子……你旁边有人吗？
2. 小梦：杯子没人领。座位也没有。
3. 小五：你刚才哼的，是周杰伦那首？
4. 小梦：你听见了？
5. 小五：就最后一点。
6. 小梦：喏。比下面那个音响好听。

【选项 A】接过耳机，坐近一点。

- 小五：线是不是不够长？
- 小梦：是你坐得太远。
- 小五：现在呢？
- 小梦：嗯。别再往下掉了。
- 【动作】她用帽子给他让出半个座位。
【共同回应】
- 【旁白】耳机线搭在两个人的校服袖口之间。他连换个坐姿，都比刚才小心。
- 【小梦心声】这样才听得见。嗯，我说的是歌。
- 【记录】第一次听歌＝一起听。
- 【去向】S02。

【选项 B】先问她在听哪一首。

- 小五：我怕认错。歌名是什么？
- 小梦：《蒲公英的约定》。
- 小五：那我没认错。
- 小梦：确认完了，可以坐下了吧？
- 【动作】她把耳机又往前递了一点。
【共同回应】
- 【旁白】她没把耳机收回去。那半个位置，也一直空着。
- 【记录】第一次听歌＝问过歌名。
- 【去向】S02。

【选项 C】指指下面，先去帮忙搬椅子。

- 小五：他们在叫我。我得下去一趟。
- 小梦：好，那你小心台阶。
- 小五：歌名下次告诉我？
- 小梦：你下次记得来问。
【共同回应】
- 【旁白】他下台阶时回头看了一眼。她还坐在那里，指尖绕着另一只耳机。
- 【记录】第一次听歌＝还没一起听。
- 【去向】S02。此处不减少获得恋爱路线的机会。

## S02｜这不是猫

【时间】军训结束后的第二周，课间。

【旁白】那以后，课间借东西成了他绕到窗边的理由。

【小梦心声】怎么每次都刚好少带一支笔。

【旁白】她把备用笔放在桌角。第二天，还是放在那里。

【画面】阳光照着课桌，窗边搭着值日抹布。小梦在右侧收英语笔记，小五站在桌边。笔记角落有一只戴眼镜的奇怪小动物；不要把整页文字画进背景。

【承接，只播放一句】

- S01 一起听：小梦：今天坐这儿，不用担心耳机线了。
- S01 问过歌名：小梦：你后来有没有搜那首歌？
- S01 没一起听：小五：我来补问那首歌的名字。

1. 小五：还有……英语笔记能借我一下吗？
2. 小梦：最后一节你又没记？
3. 小五：记了。只记到老师翻页之前。
4. 小梦：明早还我。我还要背。
5. 小五：你最后这只猫，挺像个人的。
6. 小梦：那就是人。

【选项 A】压低声音：“班主任？”

- 小梦：你小点声。
- 小五：眼镜画得挺传神。
- 小梦：再说我不借了。
- 【动作】她把本子推过来，手却还压着那一角。
【共同回应】
- 【旁白】他凑近了一点。她先看门口，又忍不住看他憋笑的样子。
- 【记录】笔记回忆＝班主任画像。
- 【去向】S15。

【选项 B】翻到空白处，补画一只真正的猫。

- 小梦：你画之前不问一下？
- 小五：那我擦掉。
- 小梦：等等。它怎么有六条腿？
- 小五：……跑得快。
- 【动作】她笑得低下头，把橡皮拿走了。
【共同回应】
- 【旁白】她嘴上嫌弃，收本子时却特地把那页的折角抚平。
- 【记录】笔记回忆＝六条腿的猫。
- 【去向】S15。

【选项 C】把本子合好：“秘密，我没看见。”

- 小梦：你现在这个表情很不可信。
- 小五：我明天连人带本子一起送来。
- 小梦：人就不用了。本子别忘。
【共同回应】
- 【小梦心声】他明明看见了。可有人认真替自己装不知道，好像也不错。
- 【记录】笔记回忆＝替她保密。
- 【去向】S15。

## S15｜借你一支笔

【时间】高一下学期，午后的自习课。

【旁白】英语听写前，他翻了两遍笔袋，唯一一支笔还是没水。
小五：那个……
小梦：又没带笔？
小五：这次带了。它临时不想工作。
【旁白】她笑了一下，把桌角那支蓝色的推过来。
小梦：先用这支。别咬笔帽。
小五：你怎么知道我——
小梦：上次还回来的时候，帽子扁了一点。
【旁白】他赶紧把手往回缩。她也正好伸手去拿笔，两个人的指尖轻轻碰在一起。
【分镜】school-fingers
【动作】她的手停了一瞬。他先松开了笔，笔滚到两张课桌中间。
【小五心声】只是碰了一下。为什么连它滚了几圈，我都数得那么清楚。
小梦：……掉了。
小五：我捡。
【旁白】他们同时低头，差一点碰到额头，又都坐直了。
【小梦心声】我明明只是想把笔递给他。怎么耳朵也跟着热起来。
小梦：老师要开始了。
小五：嗯。
【旁白】那次听写的第一个单词，他漏了开头两个字母。

【选项 A】认真说谢谢，把笔轻轻接好。

小五：谢谢。我会好好还的。
小梦：一支笔而已，你怎么这么郑重。
【旁白】她把视线移回黑板，嘴角却没有完全收住。

【去向】S03。

【选项 B】压低声音：“这次不咬笔帽。”

小梦：那也别把它借丢了。
小五：人还在，就不会丢。
【小五心声】说完才发现，这句话听起来好像不止是在说笔。

【去向】S03。

【选项 C】把自己的橡皮放过去，当作抵押。

小梦：这只橡皮怎么缺一角？
小五：有使用经验，比较可靠。
【旁白】她把那只旧橡皮和自己的放在一起。一直到下课，都没有再推回来。

【去向】S03。

## S03｜这一行开始

【时间】高二，两人成了同桌。晚自习。

【旁白】这一年，他们已经借过许多支笔，也走过许多个放学后的路口。

【旁白】换座位那天，他把名字看了两遍，才装作随便地走到她旁边。

【小五心声】原来一张座位表，也能让人高兴一整天。

【画面】相邻的课桌，数学卷子、英语练习、橡皮屑。小五在左，小梦在右；草稿纸放在两人中间。窗外是操场灯，后排同学只用简化剪影。

【旁白】分班后的第三天，她第一次把数学卷子推过来。

1. 小梦：最后一道，你会吗？
2. 小五：第一问会。后面得试一下。
3. 小梦：够了。我卡在第一问前面。
4. 小五：先看这里。到这一步懂吗？
5. 小梦：嗯。
6. 小五：那下一行呢？
7. 小梦：……你先写。

【选项 A】把纸推回中间：“哪一行开始没懂？”

- 小梦：再上一行。
- 小五：这里？
- 小梦：还得上一行。
- 小五：行。那我刚才讲快了。
- 小梦：你别叹气就行。
【共同回应】
- 【旁白】她把椅子挪近了一点，近得他能看清她压在卷子上的发梢。
- 【记录】讲题习惯＝允许说不懂。
- 【去向】S04。

【选项 B】先停下来，承认自己也算错了。

- 小五：等一下。我这个负号也漏了。
- 小梦：你刚才讲得可肯定了。
- 小五：现在可以一起不会了。
- 小梦：那你先擦。我找答案解析。
【共同回应】
- 【旁白】他们同时去拿橡皮，又同时让开。那道题因此又多算了两分钟。
- 【记录】讲题习惯＝一起查错。
- 【去向】S04。

【选项 C】把完整步骤写给她，让她慢慢看。

- 小梦：我看得懂你写的，换道题就不会了。
- 小五：那明天找一道类似的？
- 小梦：好。今天我先回去试试。
【共同回应】
- 【旁白】第二天他真的多找了一道题。她接过纸，先在边角画了一个小小的勾。
- 【记录】讲题习惯＝留到明天再试。
- 【去向】S04。这里是节奏不同，不判定为不体贴。

## S04｜明天下午有球赛

【时间】周五午后。

【旁白】他说来找她，是要借订书机。篮球却一直抱在怀里。

【小梦心声】借东西的人，怎么站了半天还不走。

【旁白】她低头理稿子，把写错的同一个字描了两遍。

【画面】教室后门，小五抱球，小梦坐在窗边改校园广播站的试音稿。稿子上只有简短划线，不呈现大段可读文字。风把门口值日表吹起一角。

1. 小五：明天下午，我们班打球。
2. 小梦：我知道。你们贴了三张海报。
3. 小五：你来吗？
4. 小梦：两点有广播站试音。不知道几点完。
5. 小五：你真报名了？
6. 小梦：嗯。念错名字应该不会当场赶我走吧？

【选项 A】“结束了再来，我给你留个位置。”

- 小梦：你在场上，怎么留？
- 小五：让书包替我坐着。
- 小梦：那它别挡别人。
【共同回应】
- 【旁白】她拿笔在日程表的两点后面画了一个很浅的圈。
- 【记录】球赛约定＝等她试音后再来。
- 【去向】S05。

【选项 B】“要不要先拿我练一遍？”

- 小梦：你听得出问题吗？
- 小五：至少能听出你有没有叫错我名字。
- 小梦：那请这位小五同学保持安静。
【共同回应】
- 【旁白】她念第一句时看了他一眼。只那一下，他后面听见的字就全乱了。
- 【记录】球赛约定＝一起练过试音。
- 【去向】S05。

【选项 C】“试音要紧，球赛下次还有。”

- 小梦：你不是说这场很重要？
- 小五：重要。你的也重要。
- 小梦：那我结束了给你报结果。
【共同回应】
- 【旁白】他走到门外才发现订书机还没借。她在座位上看着，笑了很久。
- 【记录】球赛约定＝互相报结果。
- 【去向】S05。

## S05｜你也没进？

【时间】球赛当天傍晚。

【旁白】他在售货机前翻硬币，听见身后的脚步便抬了头。

【旁白】她原本可以从另一边回家，却把那张试音稿折小，坐到他旁边。

【小梦心声】也许不用马上说点有用的话。先在这里坐着就好。

【画面】体育馆外的自动售货机，夕光把球网影子投在墙上。小五坐左侧矮台，球停在鞋边；小梦右侧拿着折过的试音稿。机器里饮料轮廓各不相同。

【承接】

- S04 A：小梦：我看见你书包了。可惜来晚了。
- S04 B：小梦：今天念到“小五同学”，我差点笑出来。
- S04 C：小梦：来报结果了。你先说还是我先说？

1. 小五：我们输了，一分。
2. 小梦：我也没选上。
3. 小五：他们怎么说？
4. 小梦：让我下次慢一点。其实我自己也听出来了。
5. 小五：那你现在想——
6. 小梦：先别给建议。我刚被指导了半小时。

【选项 A】买两瓶水，陪她坐一会儿。

- 小五：那现在休息。
- 小梦：你不复盘球赛？
- 小五：再过五分钟。
- 小梦：行。我也五分钟以后再努力。
【共同回应】
- 【分镜】school-water
- 【旁白】瓶身上起了一层水珠。他们没再说输赢，把这一小会儿安静坐完。
- 【记录】安慰回忆＝一起坐了五分钟。
- 【去向】S16。

【选项 B】问她愿不愿意去吃点东西。

- 小五：校门口的烤红薯，去不去？
- 小梦：你请？
- 小五：两位落选选手，各付各的。
- 小梦：小气。帮我挑个小的。
【共同回应】
- 【小梦心声】其实不是非要吃红薯。是还想再和他走一段路。
- 【记录】安慰回忆＝一人一个烤红薯。
- 【去向】S16。

【选项 C】讲讲自己最后那次失误。

- 小五：最后一球，我以为自己特别帅。
- 小梦：然后呢？
- 小五：球连框都没碰着。
- 小梦：好。现在我觉得念快一点也不算什么了。
【共同回应】
- 【旁白】讲到最后一个球，他自己也笑了。她先看着他，才跟着笑起来。
- 【记录】安慰回忆＝没碰到框的球。
- 【去向】S16。

## S16｜要不要吃一点甜的

### 连续性与实现边界

- 小梦的高中试音没选上，大学重新加入校园电台；不能写成高中已成为正式主持人。
- 小五在高中明确考虑海外本科，拿到的是有条件录取；高考后条件满足、办理出发手续。不要写成一夜之间决定出国就能入学。
- 小梦与小五正式交往后，后续恋爱线才使用拥抱、男朋友称呼。朋友线只有自己的 F01/E03，不借用恋爱分手回忆。
- S12 代班可拒绝，且承诺在先。这是安排与沟通的选择，不是用失去工作来惩罚不听直播。可以接班并提前改约，也能到圆满。
- B11 的工作已经是小五独立认可且接受的选择。小梦不以“证明爱我”要求他辞职、搬家或上交行踪。
