## 画面

新增六份人物分镜图集，共绘制 24 幅画面，其中 23 幅已接入。大学视频通话的另一个候选画面因两地关系不够清晰，保留为素材，未用于游戏。另制作一张独立封面，用于游戏与 README。

新图以人物、手、表情和距离为重点，环境只保留必要的课桌、长椅、伞、车窗或道具。部分原有环境图继续使用，并非全部背景已重绘。

递笔、买冰淇淋、分享和靠肩均有动作前后的不同画面；动作句出现才切换。机场拥抱、桥边拥抱、大学重逢、第一次牵手、买菜与做饭接入对应分镜。同幕换分镜柔和叠化，跨场保留淡出字幕与淡入。每句话都等待玩家推进，不自动跳过。

这些是插画分镜，不是逐帧人物骨骼动画。原先规划的全套透明角色动作库仍未制作。

## 界面与字体

使用粉色、浅蓝、奶油白的贴纸风界面，替换原来的编辑式封面布局。气泡、选项、工具按钮和菜单统一圆角、浅彩与圆润字形。继续固定一屏，游玩页面无上下滚动。

字体随项目打包为 ZCOOL KuaiLe（站酷快乐体），不再依赖系统幼圆是否安装。设置中有字体样例，提供 24 / 28 / 32px；默认 28px。字体许可保存在 `public/fonts/OFL.txt`。
