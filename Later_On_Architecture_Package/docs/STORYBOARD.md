## 播放与存档

- 每个【分镜】指令绑定之后第一句可见对白或动作；随后沿用，直到出现下一条指令。图集编号不显示给玩家。
- 每个选项的回应都有姿态、道具和双人／异地／单人构图绑定；原图集镜头继续作为剧情索引。普通对白保留当前姿势，动作切换时接续上一姿势。
- 镜头仅由剧本进度推导，重载、回看、重选时一致；预览下一步不改存档。
- 下一镜和选择后的首镜准备成功后才提交进度；加载失败可以重试或使用简化画面继续。
- 剧情版本2.1.0增加可见对白，旧版当前进度不直接续接；已解锁结局保留。
- 保留五段已有原创配乐和逐句阅读，音乐随情绪变化。

## 当前边界

这是插画分镜播放，加入了轻微镜头推进、蒸汽、心动符号、边缘雨线和公交窗边光影，绑定见 src/domain/motion.mjs。菜单、加载、错误提示、标签页隐藏时暂停；阅读设置及系统减少动态偏好均生效。每段动态只由当前镜头决定，不推进剧情、不写入存档，同一镜头的普通对白不会重复播放入场动态。

已补入独立人物部件与二维关节动画：头、身体、手臂和左右腿分层，递笔、掉笔、弯腰、靠肩、牵手、迈步、拥抱、松开等动作由关键帧连续插值。全部节点的选项均绑定动作与道具，详见 ANIMATION.md。原有图集保留，不另做逐帧原画。

接续修订已覆盖全剧149处具体动作，见 ACTION_COVERAGE.md，包含非等时长阶段、原位停顿与独立手腕。新封面、全部正文与动画部件的资源回归加入后，2026-10-25全套39项测试通过，素材、TypeScript检查和生产构建通过。没有启动浏览器；实际游玩、声音与摄像头效果仍需设备验收。详细结果见 IMPLEMENTATION_STATUS.md。
